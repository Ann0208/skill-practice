# 西葡专属旅行页实现计划

## 目标

把隐藏页面整理成“城市 → 日期 → 景点 → 点到点交通”的可访问旅行决策页，保留 09/24 的辛特拉雷加莱拉庄园和贝伦区完整路线，不展示跨城交通比价，并使用 Excel 已订酒店信息。

## 阶段

- [x] 核对 Excel 住宿和行程修正，确认现有页面结构与遗留旧脚本。
- [x] 补齐马德里、巴塞罗那逐日点位、交通段、耗时和价格依据。
- [x] 重写页面脚本，使日期切换、地图点位、路线连线和日程同步。
- [x] 清理旧文案与旧字段，检查 09/24、酒店和离境时间。
- [x] 构建、脚本语法检查、浏览器交互与移动端验证。
- [x] 只提交旅行页并部署隐藏链接。

## 关键决策

- 跨城交通只作为“已完成移动”的日程上下文，不做价格比较。
- 地图只显示当前选中城市和日期的点位及逐段连线。
- 每条路线段显示起点、终点、方式、耗时、价格/依据和执行备注。
- 酒店名称与地址采用行程总表已订信息；不覆盖用户未提交的 CSS 修改。

## 风险与校验

- 规划耗时/价格与现场班次、排队、施工有关，页面标注“Excel”或“规划”，并提示出发前复核。
- Leaflet 依赖 CDN；CDN 不可用时，文字行程和交通明细仍可读。
- Hexo 构建存在项目既有 `hexo-wordcount` 警告，需以退出码和旅行页生成结果为准。
